# Ghost Ships — B2 / FCE, 90 хв

Інтерактивний урок: Mary Celeste та Baychimo. Один `index.html` + папка `media`.

## Що покласти в папку media
- `mary-celeste.jpg` — вже є (ілюстрація двощоглового корабля); за потреби замініть на справжнє фото Mary Celeste.
- `joyita.mp3` — запис аудіювання (скрипт у файлі ghost-ships-recording-scripts.md).
- `dictation.mp3` — запис диктанту (3 читання: цілий текст, по фразах з паузами, цілий текст).
- `baychimo.jpg` — вже є.

Назви файлів мають бути саме такими (малими літерами).

## Деплой (GitHub + Vercel)
1. Створіть папку `ghost-ships` у репозиторії сайту й покладіть туди `index.html` і `media/`.
2. Закомітьте та запуште — Vercel опублікує сам.
3. Додайте картку на головну сторінку «Interactive Lessons».

## Режим вчителя
Додайте `#teacher` в кінець адреси (наприклад `.../ghost-ships/#teacher`). З'являється кнопка «Show answers» у кожній вправі й вибір фото в порожніх слотах.

## Збереження у Word
Кнопки «Save as Word (.docx)» є в диктанті та в історії. На вашому сайті файл завантажується одразу; у перегляді claude.ai браузер питає підтвердження.
